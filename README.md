# Privacy Policy

*Last updated: 2025-05-03*

## 1. Introduction

Token Setter (the “Extension”) is designed solely to enable developers to set, update, and manage authentication tokens in their browser. This Privacy Policy explains how the Extension handles data and user privacy.

## 2. Single Purpose

The Extension has a single, narrow purpose: to manage authentication tokens for the current site. It does **not** collect, transmit, or share any personal or usage data beyond what is required to fulfill this purpose.

## 3. Data Collection and Use

* **No Personally Identifiable Information (PII):** The Extension does **not** collect any user’s name, email, address, or other PII.
* **No Usage Analytics:** The Extension does **not** collect usage statistics, click events, browsing history, or telemetry data.
* **Local Storage Only:** All tokens and settings are stored locally in your browser’s storage. No data is sent to any external server.

## 4. Cookies

The Extension may read and write browser cookies on the current site solely to store authentication tokens. These cookies remain under the control of the user’s browser and are not transmitted externally by the Extension.

## 5. Permissions

The Extension requests the following permissions for its sole functionality:

* **activeTab:** To identify the current tab’s URL and apply tokens to the correct origin.
* **cookies:** To read and write authentication cookies on the current site.
* **storage:** To save tokens and user preferences across browser sessions.
* **scripting:** To inject a script into the page context that sets the authentication token.
* **Host permissions (`*://*/*`):** To operate on any site where you choose to set a token.

## 6. Remote Code

The Extension does **not** load or execute any remote code. All scripts and resources are packaged within the Extension itself.

## 7. Third-Party Services

This Extension does **not** integrate with any third-party analytics or advertising services.

## 8. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted here with an updated "Last updated" date.
